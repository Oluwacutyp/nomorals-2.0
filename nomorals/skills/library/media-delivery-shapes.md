# Media delivery shapes

The delivery-shape law: media arrives in consumable form, or the work
is not done.

- A photo request delivers an inline photo — never a raw file with a
  hash name. A GIF delivers as an animation, not a still or a document.
- A couple profile picture is TWO separate profile-ready pictures, one
  per person — never one combined image.
- Sources diversify: multiple providers per media kind, plus her own
  generation as a rung. A single anime API is a seed, never the closed
  list.
- Play and download carry measured progress and per-kind acceptance
  contracts — the delivered artifact is checked against the contract
  for its kind before it is called done.
- Emoji live inside text and reactions; stickers are standalone
  messages. They are different organs — never report one as the other.
